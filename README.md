Entry for the make.fun bounty [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2).

`main.py` (Python 3.13, standard library only) writes exactly one word to `/output/entry.txt` — the word the entrant's ex would use to describe them. The funniest, most painfully honest one-word self-portrait wins.

Run it:

```sh
python3 main.py
```
